
# Car Showcase — CCT360 Lab 6

A responsive car showcase website built using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Three-image car carousel
- Six vehicle gallery cards
- Expandable vehicle details
- Individual Quick View dialogs
- Responsive mobile navigation
- Contact form with validation

## Pages
- index.html — Homepage and vehicle gallery
- contact.html — Contact form

## Live Website
[View Car Showcase](https://musasid7-max.github.io/lab-6/)


## Testing

The website was tested on desktop and mobile screen sizes.

- Carousel navigation works with previous and next buttons.
- All six vehicle cards display in a responsive layout.
- Quick View dialogs open and close.
- Expandable vehicle details work.
- Mobile navigation opens and closes.
- Contact form validates required fields.


## Project Structure

- `index.html` — Homepage, carousel, and car gallery
- `contact.html` — Contact form
- `css/bootstrap.min.css` — Bootstrap styles
- `css/style.css` — Custom carousel styling
- `js/bootstrap.bundle.min.js` — Bootstrap JavaScript
- `images/` — Vehicle images

## Technologies Used

HTML5, CSS3, Bootstrap, and JavaScript.
